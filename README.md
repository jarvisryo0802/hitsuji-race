# まかいの ひつじレース

小学生向けの「ひつじ育成＋レース」ゲームです。
1日の遊べる量に上限があり、5〜10分で今日のぶんが終わる作りになっています。

> 実在の牧場とは関係のない、こども向けの非公式ファンゲームです。

## あそぶ

**https://jarvisryo0802.github.io/hitsuji-race/**

iPhone の **Safari** でこのURLを開き、共有ボタン → **「ホーム画面に追加」** してください。
アプリのようなアイコンが並び、Mac がなくても、電波がなくても遊べます。

> **注意：** ファイルアプリから `index.html` を直接タップしても動きません。
> ファイルアプリのプレビュー（クイックルック）は JavaScript を実行しないためです。
> かならず Safari で URL を開いてください。

## そうさ

**画面を指で押したまま動かすと、主人公が牧場を歩きます**（どうぶつの森のような見下ろし画面）。
羊・自販機・ガチャ・レースゲート・スタッフに近づくと、その場所を**直接タップ**して話しかけられます
（画面下の緑のボタンからでも同じことができます）。近づく前にタップした場合は
「もっとちかづいてね」と表示されます。

牧場は入口（左下）から右へ進むと まず おさんぽ やぎ があり、右上（すこし左より）に
ひつじの さく と エサの じはんき があります。そこから さらに ずーっと右へ歩くと
いちばん奥に レースかいじょう。とちゅうで 下へ分かれる道を進むと、画面の
いちばん下に じょうばたいけん があります（歩いていくワクワク感を出すため、
わざと入口から遠くに配置しています）。

| 行き先 | できること |
|---|---|
| ひつじの さく（右上） | ステータス確認・ごはん・ブラッシング・さんぽ |
| エサの じはんき（さくの近く） | エサを買う（会話形式） |
| じょうばたいけん（画面いちばん下） | 障害物ジャンプゲーム（800えん、回数制限なし） |
| おさんぽ やぎ | ルーレット＋ゴールまで みちを外れないよう誘導するミニゲーム（500えん、回数制限なし） |
| レースかいじょう（いちばん右奥） | 羊レース（500えん、回数制限なし） |
| ガチャ（入口付近） | 300えんで1回 |
| スタッフ | ヒント・ひつじの様子を聞ける。毎日ちがう場所にランダムで現れる |

レース・おさんぽやぎ・じょうばたいけんは1日の回数制限をなくし、
所持金があるかぎり何度でも遊べるようにしてあります（お金がなくなればそこで打ち止め）。

右上の **⚙ ボタン**から「あそびかたを みる」と
**「🔄 さいしょから やりなおす」**（データ全消し）が選べます。
🎒 ボタンはレース用の わざ・どうぐの持ち物です。

## 1日の あそびかた

1. アプリを開くと **おこづかい 300えん** がもらえる
2. **ひつじの さく**で おせわを 3回 する（ステータスが のびる）
3. **エサの じはんき**で エサを買う（100えん〜）
4. **レースかいじょう**（500えん）・**おさんぽ やぎ**（500えん）・
   **じょうばたいけん**（800えん）に、お金が続くかぎり何度でも挑戦できる
5. あまったお金で **ガチャ**（300えん）

### おせわ（3種類）

| おせわ | 内容 | のびる |
|---|---|---|
| ごはんを あげる | 柵の外からエサを見せて呼び、指で動かして口もとに近づけて食べさせる | エサによる |
| ブラッシング | 10秒（メーター表示）以内に よごれを全部タップ | なかよし |
| さんぽ | メーターを みどりの真ん中で止める | スタミナ |

**ごはん**は牧場の柵の外からあげる体験にしてあります。エサを見せると
ひつじが牧場の奥から気づいて歩いてきます（約3秒）。来たあとは画面を指で
動かして エサ（手）をひつじの口もとに近づけると食べはじめます。あっちに
持って行ったりこっちに持って行ったり、じらして遊ぶこともできます。
にげられずに食べさせきれると なかよし度にボーナスが付きます。
その日食べたいエサ（ヒントは牧場画面のふきだし）を当てると大成功です。

### レース

- ひつじ **4頭**で、はしから はしまで がめん3つぶんくらいの **おおきな だえんコースを 1周**（およそ 30〜35秒）
- カメラは じぶんの ひつじを おいかけて よこに スクロールします
- **見守るのがメイン**。わざボタンは **1レースに1回**だけ押せます
- わざは 使うタイミングで効果が変わります
  - 🌀 コーナーマスター → カーブの途中で
  - 🔥 ふんばり → ゴール前で
  - 🌪 おじゃま！ → 前にひつじがいるときに
- 押しどきになるとボタンが光ります
- 賞金：1位 1000えん／2位 500えん／3位 250えん／4位 100えん

観客の歓声、順位が変わったときの実況、最終直線での曲の加速など、
見ていて盛り上がるようにしてあります。

### わざの おぼえかた

- はやさ 25 で 🌀 コーナーマスター
- スタミナ 25 で 🔥 ふんばり
- なかよし 25 で 💖 なかよしパワー
- 🌪 おじゃま！ と 🛡 もふもふバリア は ガチャのみ

ライバルの強さは 自分のステータスに合わせて変わるので、
育てても育てなくても 接戦になります。

### おさんぽ やぎ（500えん）

全画面表示の「ゴールまで たどりつけるか」ミニゲームです。

1. まず **ルーレット**で今日おさんぽする やぎの **レベル（1〜10）** が決まる。
   レベルが高いほど当たりにくいが、成功したときの ごほうびが豪華になる
2. 画面が縦にどんどんスクロールし、やぎが自分から左右にふらふら歩こうとする
   （道から外れている方向へ さらに逆らって進みたがる）。道の外は草地になっていて、
   はみ出すと道草を食べて **おなかいっぱいメーター**（画面上部）が たまる。
   ゴールに近づくほど 道は少しずつ せまくなる
3. 画面を指で **ドラッグ**して やぎを 道の上に誘導する。やぎは おもいので、
   おなじ方向にしばらく引っぱり続けて、じわじわ動かす感覚。主人公がリードを
   持ってヤギと歩く様子が見え、草地にいる間はヤギが実際に草を食べて画面が
   赤く点滅する。画面左上に **現在地／ゴールまでの距離** が表示される
4. **ゴール（40m）** に たどりつけたら せいこうで、やぎのレベルに応じた
   ごほうび（エサ・どうぐ・わざ・お金）が1つもらえる。メーターが満タンに
   なると、そこで失敗（少しのステータスだけ もらえる）

### じょうばたいけん（800えん）

全画面表示のエンドレス障害物ジャンプゲームです。**画面のどこをタップしても馬がジャンプ**します
（低め・ふわっとした ジャンプで、ジャンプ中は脚を折りたたむ）。背景には地面と
つながった富士山（ほぼ固定）・雲・丘・地面の流れる線があり、進んでいる感覚がわかる
ようになっています。先に進むほど障害物が大きく・高頻度になり、タイミングがシビアに
なります（木の柵のほか、たまに水たまりも出ます）。障害物の間隔は、必ず1回の
ジャンプで越えられる広さを基本にしつつ、たまに広い休憩区間やタイトな連続配置を
まぜて単調にならないようにしています。障害物に **3回** 当たるとそこで終了。
**何メートル進めたか**を競い、ハイスコアはトップ10まで保存されます
（アイテムの報酬はなし、記録に挑戦するミニゲーム）。

## こまったとき

**データを最初から消したい**（テストのやり直し、別の子が遊ぶ、名前を変えたい等）
牧場画面の右上 **⚙ → 「🔄 さいしょから やりなおす」**。確認画面が出ます。

**おせわの回数を増やしたい**
`docs/js/data.js` の `CARE_PER_DAY` を変えてください。
レース・おさんぽやぎ・じょうばたいけんは回数制限がなく、`RACE_PRICE` /
`GOAT_PRICE` / `HORSE_PRICE` の金額だけが かかります。

## ファイル構成

```
docs/
  index.html            画面の枠組み
  style.css             みため
  js/data.js            エサ・わざ・ガチャなどのデータ（バランス調整はここ）
  js/save.js            セーブと 1日のきりかえ
  js/sheep.js           ひつじの絵
  js/ui.js              画面切替・音・演出・会話ウィンドウ
  js/map.js             牧場マップ（歩く・カメラ・場所の判定）
  js/farm.js            おせわ・じはんき・ガチャ
  js/race.js            レース
  js/goat.js            おさんぽ やぎ（ルーレット・みちを外れないミニゲーム）
  js/horse.js           じょうばたいけん（ジャンプゲーム・ハイスコア）
  sw.js                 オフラインで遊ぶための Service Worker
  precache.json         ためこむファイル一覧とバージョン（更新時はここ）
  manifest.webmanifest  ホーム画面に追加したときの設定
```

GitHub Pages は `main` ブランチの `/docs` フォルダから公開されています。

## 中身を変えたいとき

おもな調整箇所は `docs/js/data.js` の先頭です。

- `ALLOWANCE` … 毎日のおこづかい
- `CARE_PER_DAY` … 1日にできる おせわの回数
- `RACE_PRICE` / `GOAT_PRICE` / `HORSE_PRICE` … レース・おさんぽやぎ・
  じょうばたいけん 1回あたりの料金（回数制限はなし）
- `RUNNERS` … レースに出るひつじの数（変えたら `PRIZE` と
  `docs/js/race.js` の `LANE`（コースのレーン）も同じ数にそろえる）
- `LAPS` / `RACE_SECONDS` … レースの長さ
- `PRIZE` … 賞金
- `FOODS` / `SKILLS` / `ITEMS` / `GACHA_POOL` … 中身とレア度
- `goatLevelWeight` / `GOAT_REWARDS` / `GOAT_GOAL_M` … おさんぽやぎの
  レベル抽選確率・ごほうび内容・ゴールまでの距離（メートル）
- `HORSE_STAGES` / `HORSE_LIVES` / `HORSE_GRAVITY` / `HORSE_JUMP_V` …
  じょうばたいけんの難易度カーブとジャンプの物理

**変更したら `docs/precache.json` の `"cache": "makaino-sheep-v18"` の数字を1つ増やしてから push してください。**
これを忘れると、ホーム画面に追加済みの端末で古いままになります。
ファイルを増やしたときは、同じ `precache.json` の `files` にも追加してください。
