# ひつじレース

小学生向けの連打レースゲームです。

## あそぶ

**https://jarvisryo0802.github.io/hitsuji-race/**

iPhone の **Safari** でこのURLを開き、共有ボタン → **「ホーム画面に追加」** してください。
アプリのようなアイコンが並び、Mac がなくても、電波がなくても遊べます。

> **注意：** ファイルアプリから `index.html` を直接タップしても動きません。
> ファイルアプリのプレビュー（クイックルック）は JavaScript を実行しないため、
> 画面は表示されてもボタンが反応しません。かならず Safari で URL を開いてください。

## あそびかた

- **ひとりで あそぶ** … 自分のひつじと、ライバルの強さ（やさしい／ふつう／むずかしい）を選びます
- **ふたりで あそぶ** … 画面を左右に分けて、兄弟や友だちと対戦できます
- スタートしたら、下のオレンジ（青）のボタンを**連打**するとひつじが速く走ります
- 走っている途中で「ダッシュ！」「くさを たべた」などのハプニングが起きます
- 5とう中の順位とタイムが結果画面に出ます。1位の回数と自己ベストは端末に記録されます

## 強さの目安

シミュレーションで確かめた、1位になれる確率です。

| 連打の速さ | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 2回/秒 | 32% | 0% | 0% |
| 4回/秒 | 99% | 31% | 5% |
| 6回/秒 | 100% | 84% | 36% |
| 8回/秒 | 100% | 98% | 72% |

1レースはおよそ 14〜16 秒です。
低学年の子には「やさしい」、慣れてきたら「ふつう」がちょうどよい設定です。

## ファイル構成

```
docs/
  index.html            ゲーム本体（1ファイルで完結）
  sw.js                 オフラインで遊ぶための Service Worker
  manifest.webmanifest  ホーム画面に追加したときの設定
  icon-*.png            アイコン
```

GitHub Pages は `main` ブランチの `/docs` フォルダから公開されています。

## 中身を変えたいとき

`docs/index.html` の上のほうにある定数を書きかえます。

- `DIFF` の `cpu` … ライバルの速さ（大きいほど強い）
- `PLAYER_MIN` … 連打しないときの速さ
- `PLAYER_SPAN` … 連打でどれだけ速くなれるか
- `DISTANCE` … ゴールまでの距離（レースの長さ）
- `SHEEP` … ひつじの名前と色

変更したら `docs/sw.js` の先頭にある `CACHE = "hitsuji-race-v1"` の数字を
1つ増やしてから push してください。これを忘れると、
ホーム画面に追加済みの端末で古いままになります。

## メモ

- 縦向き専用です。横向きにすると「たてむきに してね」と表示されます
- 音は右上のスピーカーボタンで消せます
- 成績は端末ごとの保存（localStorage）です
